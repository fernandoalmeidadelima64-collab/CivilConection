# SPECs - Civil Connection

Este diretório centraliza a documentação operacional, de produto e de banco do projeto.

## Estrutura

- specs/ : visão do sistema, tema visual e telas principais
- tasks/ : backlog, roadmap e tarefas de implementação
- sql/ : scripts SQL de banco e dados iniciais
- backlog.md : visão executiva do backlog do produto

## Objetivo

Organizar o repositório em uma estrutura fácil de manter para GitHub, com documentação de produto, desenvolvimento e banco em um único ponto de entrada.
