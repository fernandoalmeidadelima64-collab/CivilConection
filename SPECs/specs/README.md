# Especificações do Sistema

## Visão geral

O Civil Connection é uma plataforma para conectar clientes, profissionais e obras do setor da construção civil. O sistema permite encontrar especialistas, acompanhar projetos, registrar diário de obra, gerenciar etapas e centralizar comunicação entre stakeholders.

## Principais módulos

1. Autenticação e cadastro
2. Vitrine de profissionais
3. Gestão de obras
4. Diário de obra
5. Dashboard de métricas
6. Painéis administrativos

## Personas

- Cliente / incorporador
- Engenheiro / arquiteto / coordenador
- Profissional técnico
- Empreiteira / construtora
- Administrador da plataforma

## Regras do produto

- A interface deve ser clara, moderna e responsiva.
- Todas as telas devem priorizar leitura rápida, busca e ações principais.
- O fluxo de obra deve ser auditável e fácil de acompanhar.
- O sistema deve apoiar o acompanhamento do progresso em etapas.
